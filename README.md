## About This Repository

This repository contains the practical work and experiments completed as part of the **Cloud Computing Laboratory**. It is organized to provide easy access to the source code, configurations, and supporting materials for each lab experiment.

The repository includes practical work related to:

* **VirtualBox and Ubuntu installation** with setup and configuration screenshots
* **Mininet installation and configuration**
* **Network topology implementation and experimentation** using Mininet
* Practical implementation of different network topologies such as **Star, Mesh, Linear, Tree, and other topologies**
* Relevant **commands, configurations, source files, and screenshots** documenting the practical work

The main purpose of this repository is to maintain a structured record of all Cloud Computing Lab activities and provide a clear reference for learning, experimentation, and future use.
